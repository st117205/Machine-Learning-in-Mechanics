# Assignment 1 — Airfoil Self-Noise

Простой и воспроизводимый эксперимент с данными NASA/UCI **Airfoil Self-Noise**.
Цель — не максимальная точность, а понятная линейная по коэффициентам модель,
которую можно объяснить физически и честно проверить на новых режимах.

## Что сделано

1. Изучены происхождение, единицы и структура данных: 1503 измерения, 5 признаков, 1 цель.
2. До обучения сформулированы гипотезы о влиянии скорости `U`, частоты `f`, хорды `c`
   и толщины вытеснения `δ*`.
3. Построены и сравнены модели:
   - baseline (среднее по обучающей выборке);
   - МНК/OLS на сырых признаках;
   - МНК на физических признаках `log10(f)`, `log10(U)`, `log10(δ*)`, `α`, `log10(c)`;
   - вариант с безразмерной частотой `log10(f·c/U)` и вариант с `U²`;
   - полиномы степени 2 и 3;
   - Ridge, Lasso и Elastic Net на полиноме степени 2.
4. Все преобразования, стандартизация и расширение признаков находятся внутри
   `sklearn.Pipeline` и пересчитываются отдельно в каждом фолде CV.
5. Степень полинома и параметры регуляризации выбираются только на обучающей части
   через 5-fold `GridSearchCV`. Тест используется один раз, после выбора модели.
6. Дополнительно проведены:
   - grouped CV по физической конфигурации `(α, c, U, δ*)` как проверка утечки;
   - проверка на полностью отложенных скоростях `U = 55.5` и `U = 71.3 м/с`;
   -bootstrap коэффициентов интерпретируемой линейной модели;
   - графики measured-vs-predicted и остатков.

Итоговый отчёт: [`results/report.pdf`](results/report.pdf).

## Источник данных

- UCI ML Repository, dataset 291: <https://doi.org/10.24432/C5VW2C>
- Brooks, Pope & Marcolini (1989), NASA, NACA 0012, безэховая аэродинамическая труба.
- Лицензия: CC BY 4.0. Локальная копия: [`data/airfoil_self_noise.dat`](data/airfoil_self_noise.dat).

| Переменная | Единица | Диапазон |
|---|---|---|
| `frequency_hz` (`f`) | Гц | 200 … 20000 |
| `angle_deg` (`α`) | град | 0 … 22.2 |
| `chord_m` (`c`) | м | 0.0254 … 0.3048 |
| `velocity_m_s` (`U`) | м/с | 31.7 / 39.6 / 55.5 / 71.3 |
| `delta_star_m` (`δ*`) | м | 0.00040 … 0.05841 |
| `spl_db` (цель) | дБ | 103.38 … 140.99 |

Цель уже дана в децибелах, поэтому коэффициенты модели — это эмпирические
наклоны в дБ, а не физические амплитуды давления. Точная нормализация
`scaled sound pressure level` в описании UCI не раскрыта; это явно отмечено
в отчёте и не заменено догадкой.

## Запуск

Нужны Python 3.9+ и пакеты из `requirements.txt` (версии подобраны под эту среду):

```powershell
cd assignment-1
py -m pip install -r requirements.txt
py -m unittest discover -s tests -v
py -m src.main
py -m src.report
```

`py -m src.main` пересчитывает все таблицы и рисунки в `results/`.
`py -m src.report` собирает PDF из уже посчитанных файлов.
Если в системе `python` не заглушка Microsoft Store, можно использовать `python` вместо `py`.

## Основные результаты

Выбранная training CV модель: `poly3_physical` — полином степени 3 от пяти
физических признаков. Модель линейна по коэффициентам; нелинейность вносится
только заранее построенными признаками.

| Подмножество | MAE, дБ | RMSE, дБ | R² |
|---|---:|---:|---:|
| Train | 1.700 | 2.291 | 0.887 |
| CV (out-of-fold) | 1.808 | 2.453 | 0.871 |
| Test | 1.810 | 2.377 | 0.890 |

Сравнение по CV RMSE, дБ:

| Модель | CV RMSE | Test RMSE |
|---|---:|---:|
| baseline | 6.830 | 7.205 |
| OLS, сырые признаки | 4.843 | 4.767 |
| OLS, физические признаки | 5.161 | 4.929 |
| Полином 2 | 3.172 | 3.240 |
| Полином 3 | 2.443 | 2.377 |
| Ridge, полином 2 | 3.170 | 3.227 |
| Lasso, полином 2 | 3.178 | 3.215 |
| Elastic Net, полином 2 | 3.662 | 3.412 |

Степень 3 выбрана потому, что CV RMSE упал с 3.172 до 2.443 дБ при 1202
обучающих объектах и 55 полиномиальных членах. Но это не «бесплатный» выигрыш:
grouped CV даёт 4.213 дБ против 2.453 дБ при обычной CV, то есть часть точности
связана с повторными частотами внутри одной конфигурации.

### Проверка на отложенной скорости

| Отложенная скорость | Модель | RMSE, дБ | R² |
|---|---|---:|---:|
| `U = 55.5 м/с` (интерполяция) | `poly3_physical` | 2.188 | 0.879 |
| `U = 71.3 м/с` (крайний режим) | `poly3_physical` | 4.929 | 0.505 |
| `U = 71.3 м/с` (крайний режим) | `poly2_physical` | 3.426 | 0.761 |

На `U = 71.3 м/с` модель систематически отказывает при углах 12.3–22.2°:
средний остаток в этой группе +2.38 дБ, а при `α = 22.2°`, `c = 0.0254 м`
недооценка достигает 19–32 дБ. Простая модель степени 2 переносится на этот
режим заметно лучше. Если цель — предсказание новых режимов, её следует
рассматривать как более безопасный выбор.

### Устойчивость коэффициентов

Бутстреп (400 повторов) базовой линейной модели показывает устойчивый знак
у `log10(f)` (отрицательный), `log10(U)` (положительный), `log10(δ*)` и угла
атаки (отрицательные). Но признаки коррелированы: `log10(δ*)` и угол атаки
имеют `r = 0.835`. При замене `log10(f)` и `log10(U)` на `log10(f·c/U)`
коэффициент `log10(c)` меняет знак и становится неопределённым. Поэтому
отдельные коэффициенты нельзя интерпретировать вне выбранной параметризации.

## Ограничения

- Всего 4 уровня скорости, поэтому проверка на отложенной скорости — грубая.
- `δ*` почти детерминирован в комбинации `(α, c, U)`; вклад этих признаков
  невозможно разделить однозначно.
- Обычная CV оптимистична из-за повторных измерений одной конфигурации;
  grouped CV и отложенная скорость дают более консервативную оценку.
- Модель не описана физически корректно в области высокого угла атаки,
  высокой скорости и малой хорды — это и есть найденный режим систематического
  отказа.
