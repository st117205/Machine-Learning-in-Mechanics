## 3. Новый проект: `poisson-lab` (этап 3)

### Решение

Сделан учебный проект-аналог на Python **без внешних зависимостей**. Вместо модуля упругости вычисляется коэффициент Пуассона по тем же 13 материалам.

Формула и соглашение о знаках:

```
nu = (dw / w0) / (dL / L0)
```

`dL > 0` — удлинение, `dw > 0` — сужение. Для нескольких измерений берётся **отношение средних деформаций**, а не среднее отдельных отношений.

### Структура

```
poisson-lab/
  main.py                  # python main.py
  poisson_lab/
    materials.py           # 13 материалов: E, плотность, справочный nu и диапазон
    calculations.py        # чистые функции + валидация NaN/Inf/нуля
    cli.py                 # интерактивный режим, --list, --demo, сохранение
  tests/test_calculations.py
  requirements.txt
  .gitignore
  README.md
  REPORT.md                # этот файл
```

### Воспроизводимый запуск и проверки

```bash
py main.py --list     # таблица всех 13 материалов + оценка G=E/(2(1+nu))
py main.py --demo     # синтетический пример: сталь, nu = 0.300
py main.py            # интерактивный ввод
py -m unittest discover -s tests -v
```

Результаты проверки на этой машине:

- **15 тестов — все OK** (0,001 с).
- `--demo`: `nu = 0.300`, расхождение со справочником 0,0%, `G = 76.9 GPa`, оба verdict — `OK`.
- `--list`: выведены все 13 материалов; для анизотропных (дуб, сосна, тик, бамбук, фанера) оценка G помечена `n/a (aniso)`.
- Интерактивный сценарий со сталью и двумя замерами прошёл без ошибок при обычной кодировке консоли.
