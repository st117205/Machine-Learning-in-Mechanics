# Assignment 0 — Poisson Ratio Lab

Учебный проект по образцу `young-modulus`: интерактивный расчёт коэффициента Пуассона для тех же 13 материалов.

## Цель

По результатам измерений (продольное удлинение и поперечное сужение) вычислить коэффициент Пуассона:

```
nu = (поперечная деформация) / (продольная деформация)
   = (dw / w0) / (dL / L0)
```

- `L0` — исходная базовая длина образца, мм;
- `w0` — исходная поперечная ширина/толщина образца, мм;
- `dL` — прирост длины, мм (положительный при растяжении);
- `dw` — уменьшение ширины, мм (положительный, когда образец становится тоньше).

Поскольку обе деформации безразмерны, единицы длины сокращаются; в программе все длины вводятся в миллиметрах.


Режимы без интерактивного ввода:

## Проверки

```bash
py -m unittest discover -s tests -v
```

Тесты покрывают: расчёт деформаций, знаковое соглашение, расчёт nu по одному и нескольким измерениям, отклонение нулевых/NaN/бесконечных значений, сравнение со справочным диапазоном, оценку модуля сдвига `G = E / (2(1+nu))`.

## Зависимости

Только стандартная библиотека Python 3.8+. Внешних пакетов нет.

## Физические допущения и ограничения

1. Линейно-упругий материал, малые деформации.
2. Для изотропных материалов выполняется `E = 2G(1+nu)`; оценка `G` выводится отсюда.
3. Древесина, бамбук и фанера анизотропны: для них указан эффективный `nu` вдоль волокон, а связь `E = 2G(1+nu)` не применяется.
4. Справочные значения приблизительные и предназначены для обучения.
5. Для устойчивого изотропного материала должно выполняться `-1 < nu < 0.5`; программа проверяет это и помечает выход за диапазон.
6. Среднее по нескольким измерениям берётся как отношение средних деформаций, что устойчивее, чем среднее отдельных отношений.
