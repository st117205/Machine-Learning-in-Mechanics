## 3. Созданный проект

**`./poisson-lab`** — учебный проект-аналог на Python без внешних зависимостей. Рассчитывает **коэффициент Пуассона** для тех же 13 материалов.

### Модель

```
nu = (dw / w0) / (dL / L0)
```

`dL > 0` — удлинение, `dw > 0` — сужение. Для нескольких замеров используется отношение средних деформаций. Для изотропных материалов дополнительно оценивается `G = E / (2(1+nu))`; для древесины, бамбука и фанеры анизотропная связь не применяется.

### Структура

```
poisson-lab/
  main.py                  # точка входа
  poisson_lab/
    materials.py           # 13 материалов: E, плотность, справочный nu и диапазон
    calculations.py        # чистые функции и валидация
    cli.py                 # интерактивный режим, --list, --demo, сохранение
  tests/test_calculations.py
  requirements.txt
  .gitignore
  README.md
  REPORT.md
```

### Запуск

Из каталога `poisson-lab`:

```bash
py -m unittest discover -s tests -v   # 15 тестов, все OK
py main.py --list                     # таблица всех материалов
py main.py --demo                     # сталь, nu = 0.300, G = 76.9 GPa
py main.py                            # интерактивный ввод
```
